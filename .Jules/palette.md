## 2025-04-04 - Screen Reader Support for Dynamic State Changes
**Learning:** Dynamically shown dialogs and automatic redirect countdowns on simple HTML pages (like login success screens) require `aria-live="polite"` and `aria-atomic="true"` to ensure screen readers announce state changes without requiring manual user focus. Furthermore, it is a best practice to place this ARIA live region on a dedicated, visually hidden (`.sr-only`), permanently present DOM element, rather than toggling `display: none` on the container itself, as some screen readers fail to reliably announce elements that transition from hidden to visible.
**Action:** Implement a dedicated screen-reader announcer element (e.g., `<div id="announcer" aria-live="polite" aria-atomic="true" class="sr-only"></div>`) and dynamically inject textual descriptions of visual state changes into it using JavaScript to ensure robust accessibility support.
