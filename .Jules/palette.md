## 2024-08-11 - Add polite ARIA announcer to dynamic redirect countdown
**Learning:** A static element containing changing countdown text often doesn't announce well with default screen reader settings if the updates are not marked as an aria-live region. Using a visually hidden DOM element with `aria-live="polite"` and updating it identically to the visual string provides an excellent a11y experience without completely redesigning the visual display structure. Expanding abbreviations ("3s..." -> "3 seconds...") further helps TTS pronunciation.
**Action:** When creating or modifying dynamic redirect countdowns, create a hidden `aria-live="polite"` div. Ensure that countdown text generation spells out abbreviations, pluralizes properly ("1 second" vs "3 seconds"), and explicitly updates both the visual text and the hidden a11y text on every tick.
