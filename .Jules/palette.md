## 2025-03-24 - Surfacing Terminal Navigation Shortcuts
**Learning:** Standard terminal shortcuts (like Ctrl+U and Ctrl+K for line clearing) are often implemented in TUI apps but remain undiscoverable to users unfamiliar with command-line emacs/readline bindings, causing unnecessary friction when editing large text chunks.
**Action:** Always surface implemented standard terminal keyboard shortcuts (e.g., in help menus or overlay hints) so that all users, regardless of terminal proficiency, can discover and utilize faster navigation/editing features.
