## 2024-10-24 - Accessible Redirect Countdown
**Learning:** For automatic redirect countdowns, using `aria-live="polite"` and `aria-atomic="true"` on a dedicated, visually hidden screen reader element ensures that users are notified predictably without being overwhelmed by assertive interruptions or screen reader confusion from dynamically added DOM elements. It is also important to handle pluralization (e.g., '1 second' vs '3 seconds') for a more polished experience.
**Action:** When implementing or modifying dynamic announcements like countdowns, always initialize the ARIA live text simultaneously with the visual text to avoid missing the initial announcement. Avoid `display: none` toggles for the announcer region; use a `.sr-only` class or equivalent inline styles to keep the DOM element permanently present but visually hidden.
