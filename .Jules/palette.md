## 2024-03-24 - Accessibility for Dynamic Redirect Countdowns
**Learning:** When using dynamic redirect countdowns, ensure the `aria-live` attribute is set to `polite` instead of `assertive` to prevent interrupting screen readers constantly. The ARIA live region should be permanently present in the DOM (visually hidden) and updated simultaneously with the visual text. Initialize the text content before any timeouts occur.
**Action:** When implementing or modifying redirect countdowns, add a dedicated visually hidden `aria-live='polite'` element using inline styles (`style="position: absolute; width: 1px; height: 1px; padding: 0; margin: -1px; overflow: hidden; clip: rect(0, 0, 0, 0); white-space: nowrap; border: 0;"`) to avoid custom CSS classes, and update its text content simultaneously with the visible text.
