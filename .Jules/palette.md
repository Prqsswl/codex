## 2024-10-08 - Accessible Link Redirect Button
**Learning:** Default un-styled `<div>` elements used as interactive buttons (especially for redirection or important links) lack keyboard accessibility. Even if JavaScript manages click events, keyboard users cannot tab to them or interact with them natively without complex custom event handlers and `tabindex="0"` bindings. Additionally, changing the tag to a semantic `<a>` link reveals default browser focus outlines which can be styled via `:focus-visible` to match the application's design system, significantly improving keyboard accessibility.
**Action:** When converting generic block elements like `<div>` to semantic interactive elements like `<a>` for accessibility, verify that its class selector does not introduce unexpected styling behavior on hover/focus, and explicitly add `:focus-visible` outlines matching the design theme (like `outline: 2px solid var(--interactive-bg-primary-default)`).
