## 2024-06-25 - Accessible Dynamic Countdowns
**Learning:** When implementing a dynamic countdown (like a redirect timer), simply updating the visual text isn't enough for screen reader users, and replacing the text content of the visible element over and over doesn't always announce well. It's better to maintain an invisible `aria-live` region (`.sr-only`) specifically for screen reader announcements, and optionally hide the visual update from screen readers using `aria-hidden="true"` to prevent double-announcing. Also, proper pluralization ("second" vs "seconds") provides a much more polished and professional experience.
**Action:** When adding or modifying any dynamic countdowns or frequently changing state, create a dedicated `.sr-only` element with `aria-live="polite"` and `aria-atomic="true"`. Update both the visual text and the screen reader text simultaneously, and implement correct pluralization.
