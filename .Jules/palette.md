## 2024-07-03 - Improve redirect countdown accessibility and grammar
**Learning:** Dynamically shown dialogs and redirect countdowns must use `aria-live` and `aria-atomic='true'`. For frequent updates (e.g., a per-second countdown), prefer `aria-live='polite'` over `'assertive'` to prevent the screen reader from constantly interrupting itself. It is best practice to place this ARIA live region on a dedicated, visually hidden (e.g., `.sr-only`), permanently present DOM element rather than toggling `display: none` on the container. Additionally, proper grammar pluralization (e.g., '1 second' vs 'X seconds') is important for a professional user experience. When applying to 'no custom CSS classes' rules, inline styles can be used for visually hiding elements.
**Action:** When implementing or fixing dynamic announcements like countdowns, always pair visual text updates with a visually hidden, permanently present `aria-live="polite"` element for screen readers. Ensure pluralization rules are explicitly handled.
