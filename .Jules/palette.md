## 2024-03-21 - Added terminal keyboard shortcuts to help menu
**Learning:** Terminal applications often support standard keyboard shortcuts (like Ctrl+U to clear line, Ctrl+W to delete word) but users may not discover them automatically. Adding them to the help menu/shortcut overlay improves discoverability and UX.
**Action:** When working on TUI applications, explicitly surface standard terminal keyboard shortcuts in help menus to improve discoverability.
