## 2024-05-24 - Accessible Countdown Timer Announcements
**Learning:** When creating dynamic redirect countdowns in static HTML pages, updating the visible text node alone does not guarantee reliable screen reader announcements, especially if the text changes rapidly (every second). Using `aria-live="polite"` on a visually hidden, permanently present DOM element ensures that screen readers can announce the changing state without interrupting themselves or missing the initial announcement.
**Action:** Always include a dedicated, visually hidden `aria-live` announcer region for dynamic countdowns and ensure the state is correctly initialized (calling the update function immediately) before triggering the `setTimeout` loop. Also, use proper grammar pluralization (e.g., '1 second' vs 'X seconds') for a polished experience.
