# Palette's Journal

## 2024-05-22 - Surfacing Implicit Interactions
**Learning:** Users often miss standard TUI capabilities (like readline shortcuts Ctrl+U/K) because they are invisible. Explicitly listing them in the UI (footer overlay) transforms "power user knowledge" into "accessible features".
**Action:** Audit other widgets (lists, inputs) for "hidden" standard bindings and consider surfacing them in context-aware hints.
