## 2024-09-21 - Convert redirect button to semantic anchor tag
**Learning:** Using a `<div>` with button styling for a link is inaccessible and prevents users from opening the link in a new tab or copying the link address. Converting it to a semantic `<a>` tag improves accessibility and usability.
**Action:** Always use semantic `<a>` tags for navigation links instead of styled `<div>` or `<button>` elements, ensuring to apply necessary CSS adjustments like `text-decoration: none` to maintain visual consistency.
