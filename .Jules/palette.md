## 2024-04-16 - Accessible dynamic redirect and semantic links
**Learning:** Adding `aria-live` directly to dynamically shown container elements can be unreliable. It is better to have a dedicated, visually hidden `sr-only` announcer element that is permanently in the DOM. Also, converting `div` buttons to `a` links for redirects improves semantic structure and keyboard navigability, requiring careful CSS resetting (like `text-decoration: none; color: inherit;`) to avoid visual regressions. Finally, starting a countdown loop with `setTimeout(tick, 1000)` instead of an immediate `tick()` prevents artificially extending the wait time on the initial UI state.
**Action:** Always use a dedicated visually hidden element for `aria-live` announcements, use semantic `<a>` tags for navigation targets with proper CSS resets, and initialize countdown states synchronously before scheduling the next tick.
