## 2024-05-24 - Accessible Dynamic Redirects
**Learning:** When using JavaScript to display a previously hidden (`display: none`) redirect countdown, screen readers often fail to announce the content correctly. Using a permanently present, visually hidden ARIA live region (`aria-live="polite" aria-atomic="true"`) provides reliable announcements. Furthermore, using `setTimeout(tick, 1000)` instead of executing the first tick synchronously gives the screen reader enough time to read the initial context before the countdown overwrites it.
**Action:** For all dynamic redirects or auto-closing dialogs, place announcements in a dedicated, visually hidden ARIA live region rather than relying on toggling container visibility, and delay periodic updates to ensure the first message is announced.
