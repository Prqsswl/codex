## 2026-05-19 - Add lightbulb emoji to tooltips
**Learning:** Text-only tips in command-line interfaces can be easily overlooked. Adding a visual cue like a lightbulb emoji draws attention and makes the hint feel more helpful and less like an error or system message. This aligns with the 'small touches of delight' philosophy.
**Action:** Always consider prepending relevant emojis to helper text, hints, or tooltips to improve visual hierarchy and draw user attention.
