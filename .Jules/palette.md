## 2024-05-04 - Screen Reader Friendly Countdowns
**Learning:** Automatically updating countdown timers (like "Redirecting in 3s...") are typically not read by screen readers unless specifically marked. Furthermore, wrapping an already styled container or an active inline text node in an `aria-live` region can cause screen readers to announce text inconsistently or skip numbers. The redirect action itself should also be focusable and operable via keyboard.
**Action:** When adding countdowns or auto-redirecting messages, add a visually hidden `aria-live="polite"` element that mirrors the countdown text explicitly. Convert non-interactive `<div>` "buttons" into semantic `<a>` links while maintaining original class names and inline styling for strict "no custom CSS" constraints.
