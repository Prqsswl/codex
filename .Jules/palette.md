## 2025-03-08 - Accessible Countdown Timers
**Learning:** When building a dynamic redirect countdown in plain HTML/JS without custom classes allowed, creating a hidden `aria-live` announcer region and updating both the visual text and the hidden text simultaneously ensures screen readers announce the changing state accurately, including correct pluralization of "seconds".
**Action:** Implement visually hidden elements with inline styles and simultaneous state updates for dynamic UI announcements where custom CSS is restricted.
