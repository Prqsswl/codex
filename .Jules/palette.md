## 2024-05-18 - Improve redirect link accessibility in login success page
**Learning:** Found an accessibility issue pattern where an interactive redirect mechanism was implemented as a `div` element rather than a semantic `a` tag. This prevented proper keyboard navigation and screen reader functionality for a critical transition step. Additionally, an associated decorative SVG icon lacked an `aria-hidden` attribute, creating unnecessary noise for screen readers.
**Action:** Always use semantic HTML elements (like `a` for navigation/redirection and `button` for actions) instead of non-semantic `div`s. Ensure focus styles are applied to these elements to maintain keyboard accessibility, and hide purely decorative SVGs using `aria-hidden="true"` to streamline the screen reader experience.
