## 2025-02-06 - Accessible Dynamic Countdowns
**Learning:** When implementing a dynamic countdown (like a redirect timer) using JavaScript, we must ensure it is fully accessible to screen reader users. The visual text changing periodically does not automatically announce itself to assistive technologies. Using a visually hidden `div` (e.g., `.sr-only`) with `aria-live="polite"` and `aria-atomic="true"` allows screen readers to announce the updates. Additionally, using proper pluralization (e.g., '1 second' instead of '1s' or '1 seconds') improves the perceived quality of the interface. We should also add `aria-hidden="true"` to the visual text so that screen reader users don't hear duplicate announcements.
**Action:** When adding or modifying countdowns, ensure an `aria-live` region is present to announce updates and use properly pluralized text.
