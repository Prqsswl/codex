## 2026-05-08 - Dynamic Redirect Accessibility
**Learning:** Screen readers often struggle to announce visually hidden or dynamically shown redirect countdowns if `aria-live` is added to a toggled container (`display: none`). Furthermore, a generic `div` lacking an explicit `href` for a redirect mechanism prevents reliable keyboard navigation and semantic predictability.
**Action:** When creating a dynamic redirect interface, always include a dedicated, visually hidden (via inline styles like `clip: rect(0,0,0,0)`) `aria-live` region on the document root to reliably announce the countdown ticks. Additionally, convert the visual button to an actual `<a>` anchor tag and dynamically set its `href` to the target URL so users can proactively tab to and interact with the redirect before the timer expires.
