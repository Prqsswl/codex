## 2024-06-18 - Screen Reader Friendly Countdown
**Learning:** Screen readers often truncate rapidly updating text in `aria-live` regions or announce it in a jarring way if not properly formatted. A dynamically updating "Redirecting in 3s..." isn't very descriptive and is easily missed or interrupted. Furthermore, using grammatical pluralization ("1 second" instead of "1 seconds") provides a significantly more polished and professional experience.
**Action:** When implementing auto-redirect countdowns, add a visually hidden `aria-live="polite"` region specifically for screen readers. Announce the full time text with proper pluralization (e.g., "Redirecting in 3 seconds..."), updating synchronously with the visual countdown. Ensure the countdown state is fully initialized on page load so screen readers don't miss the first announcement.
