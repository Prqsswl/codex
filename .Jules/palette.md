## 2024-08-14 - Accessible Countdown and Pluralization
**Learning:** Dynamic countdown text (e.g. "Redirecting in 3s") updated via JavaScript should be exposed to screen readers using `aria-live="polite"` so users are aware of the countdown without needing to focus on the element. Also, using full words ("seconds") instead of abbreviations ("s") and correctly pluralizing them (e.g., "1 second" vs "3 seconds") provides a much more polished and professional experience, especially when read aloud.
**Action:** When implementing or modifying dynamic countdowns or progress indicators, always ensure an appropriate `aria-live` attribute is set on the text container, and handle grammar correctly (pluralization and full words) for both visual clarity and screen reader pronunciation. Update the initial HTML state to match the JS logic to avoid artificial delays in screen reader announcements.
